# App Mockups

A Codex skill for creating HeroUI app mockups with the bundled page and style templates.

## Install without cloning

Paste this into a Codex chat after the repository has been pushed to GitHub:

```text
$skill-installer Install the skill from https://github.com/ic-n/prototype/tree/main/skills/app-mockups
```

The skill is available on the next turn. It includes its own HeroUI scaffold script, so cloning the repository is unnecessary. For a private repository, you need GitHub access to it.

To install an updated version, first remove the existing `app-mockups` folder from your Codex skills directory. `$skill-installer` will not overwrite an installed skill.

Then ask Codex, for example:

```text
Use $app-mockups to create a mockup for my app.
```
